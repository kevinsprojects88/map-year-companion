# Map Year Companion

> Private/personal-use async-first tabletop companion for map-based community storytelling games.

Do not include official The Quiet Year card text, rulebook text, PDFs, logos, art, or proprietary assets in repo, seed data, docs, Project files, screenshots, or shipped builds.

## MVP Spine

The MVP proves:

> A private group can play asynchronously in one app without losing the map, turn flow, discussion, decisions, or final world archive.

## MVP Must Preserve

- Async-first play
- One active player per turn
- Open chat
- Explicit official commits
- Active-player-only official map editing
- Advisory Story Polls
- Reassign Stuck Turn process vote
- Desktop/tablet authoring first
- Mobile read/respond/vote/view only
- In-app archive
- No official/proprietary content in shipped app or repo

## Hard Cuts From MVP

- Full VTT features
- Dice/combat/initiative
- Character sheets
- Public game directory
- Marketplace/assets browser
- Official bundled prompts/content
- Separate live mode
- Simultaneous drawing
- Live cursors
- Mobile map editing
- Hard turn timers
- Vote-required turn advancement
- Vote-based map approval
- Binding story votes
- Anonymous/ranked/timed polls
- AI story generation
- Export before archive MVP

## Deferred Features

- Google OAuth
- CSV card import
- Markdown export
- PDF/HTML export
- Starter maps
- Notifications/turn reminders
- Advanced map revision browser
- Public/spectator archive links
- AI-assisted lore summaries
- Custom card backgrounds/images
- Full mobile map editing

## Feature Request Test

Ask:

1. Does it help the first playable milestone?
2. Does it preserve async-first play?
3. Does it keep the map central?
4. Does it keep chat separate from official history?
5. Does it avoid generic VTT creep?
6. Does it avoid official/proprietary content risk?
7. Can a solo builder with AI help build it safely now?

If no, defer it.
